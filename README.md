# abyss ✝

Эстетический сайт в духе Dark Ether, Purple Aesthetic, Dreamcore и Witch House.
Внутри виниловый проигрыватель с альбомом Pastel Ghost — *Abyss*, ASCII-розы
и чёрный котёнок, а за кнопкой «Drift into dreams» — 3D-поле, по которому
идёшь прокруткой.

## Как открыть

Двойной клик по `index.html`, и всё работает.

Лучше запускать через локальный сервер: тогда свечение пульсирует в такт
настоящей музыке.

```powershell
py -m http.server 8765
```

После этого откройте http://localhost:8765

## Музыка

Сами MP3 в репозиторий не входят (музыка принадлежит правообладателю).
Положите свои файлы альбома в `music/` — сайт понимает такие имена:

- `01.mp3` … `10.mp3`, или
- `01 - Prism.mp3`, `02 - Embrace.mp3` …, или
- `Prism.mp3`, `Embrace.mp3` …

Если файлы называются иначе, перечислите их в `music/playlist.js`.
Ещё можно просто перетащить файлы на страницу: сайт сам разложит их по песням.

Если у песни нет файла, игла всё равно опускается и играет «ghost signal»:
сгенерированная ведьмовская колыбельная.

Трек-лист: Prism, Embrace, Clouds, Shadows, Skeleton, Dark Beach, Translucid,
Lilacs, Pulse, Abyss.

## Что где

| | |
|---|---|
| нажать на иглу / пробел | опустить или поднять иглу |
| клик по пластинке | поставить иглу в это место |
| клик по песне | сыграть её |
| котёнок | погладить |
| прокрутка во сне | идти по полю (600 м, шесть мест) |
| Esc / «wake up» | проснуться |

## Файлы

- `js/player.js`: проигрыватель, трек-лист, таймлайн, звук
- `js/ascii.js`: ASCII-розы и котёнок
- `js/field*.js`: поле сна (WebGL2, без библиотек)
- `js/cat-real.js`: чёрный кот в конце прогулки (шерсть, глаза, хвост рисуются в реальном времени)
- `css/style.css`: оформление, шрифт Grenze Gotisch
